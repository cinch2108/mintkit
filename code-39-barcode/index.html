Code 39 Barcode Generator with Optional Check Character

How it works

Code 39 encodes uppercase letters, digits, spaces and - . $ / + %. Each character is made of 9 bars and spaces, 3 of which are wide. Mintkit uses a 3:1 wide-to-narrow ratio for reliable scanning and can add the optional modulo-43 check character.

How to use it

  1. Type your text. Lowercase letters are converted to uppercase.
  2. Tick the mod-43 option if your system requires a check character.
  3. Download the PNG or SVG.

Frequently asked questions

Why are there asterisks around the text?

Code 39 always starts and ends with the * character. Scanners use it to find the barcode and don't include it in the data.

Does Code 39 support lowercase?

Standard Code 39 doesn't. Use Code 128 if you need lowercase letters or more symbols.
