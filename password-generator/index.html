Strong Random Password Generator (Secure & Private)

How it works

Each character is picked with the Web Crypto API using rejection sampling, so every character in your chosen set is exactly equally likely. The strength meter shows the real entropy in bits (length × log2 of the character set size) and how long an offline attacker at 100 billion guesses a second would need.

How to use it

  1. Choose a length. 16 or more is recommended.
  2. Pick the character sets to include, and optionally exclude look-alikes such as I, l, 1, O and 0.
  3. Generate one password, or up to 100 at once, then copy or download them.

Frequently asked questions

How long should my password be?

At least 16 random characters for important accounts. That's over 100 bits of entropy with all character sets, far beyond any brute-force attack.

Are the passwords stored or sent anywhere?

No. They're generated in your browser and never leave your device. Only your settings (not passwords) are remembered in local storage.

Is this better than Math.random()?

Yes. Math.random() is predictable and unsuitable for security. Mintkit uses crypto.getRandomValues, the same source browsers use for encryption keys.
