Online Dice Roller: d4, d6, d8, d10, d12, d20, d100

How it works

Roll up to 50 dice of any common type with an optional modifier, for example 3d6+2. Each die uses cryptographically secure, unbiased randomness, and you see every roll as well as the total.

How to use it

  1. Choose the number of dice and how many sides they have.
  2. Add a modifier if your game needs one.
  3. Click Roll. The last 15 rolls are kept in the history.

Frequently asked questions

Is it as fair as real dice?

Fairer. Physical dice have small manufacturing biases, while each side here has exactly the same probability.

What does 2d6+3 mean?

Roll two six-sided dice, add them, then add 3.
