UUID Generator: v4 and v7 (RFC 9562), Bulk

How it works

UUID v4 has 122 random bits. UUID v7 starts with a 48-bit Unix millisecond timestamp, followed by a sequence counter and random bits, so new IDs sort in creation order, which makes them better as database keys. Both use the Web Crypto API.

How to use it

  1. Choose v4 (random) or v7 (time-ordered).
  2. Set how many you need (up to 1,000) and the format.
  3. Copy them all or download a .txt file. You can paste any UUID into the inspector to decode it.

Frequently asked questions

Should I use UUID v4 or v7?

Use v7 for database primary keys, because sequential IDs keep indexes compact. Use v4 when the ID shouldn't reveal when it was created.

Can two UUIDs collide?

In practice, no. With 122 random bits, you'd need to generate billions per second for many years before a collision became likely.

Is a GUID the same as a UUID?

Yes. GUID is Microsoft's name for the same 128-bit identifier.
