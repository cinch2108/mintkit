Free QR Code Generator: PNG & SVG, No Sign-Up

How it works

Mintkit builds the QR code in your browser with a standard-compliant encoder. It picks the smallest QR version that fits your content and draws it at an exact whole-pixel module size, so it stays sharp when printed. Codes are static: the content is stored in the code itself, so they never expire and don't depend on any server.

How to use it

  1. Pick a content type: URL, text, Wi-Fi, vCard, email, SMS or phone.
  2. Fill in the fields. The code updates as you type.
  3. Optionally change the colors, error correction, size and quiet zone, or add a logo.
  4. Download a PNG for screens or an SVG for print.

Frequently asked questions

Do these QR codes expire?

No. They're static codes that hold your content directly, with no redirect service in between. They work for as long as the content (for example your website) works.

Is it really free for commercial use?

Yes. There are no watermarks, no scan limits and no sign-up, and you can print the codes on products, menus and packaging.

Which error correction level should I use?

Medium (15%) suits most uses. Use High (30%) if the code might get scratched or dirty, or if you're adding a logo. Mintkit switches to High automatically when a logo is added.

What size should a printed QR code be?

A common rule is at least 2 × 2 cm (0.8 in), and roughly one tenth of the scanning distance. Always test-scan a printed proof.
