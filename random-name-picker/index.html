Random Name Picker Wheel: Spin to Choose a Winner

How it works

Add names and spin the wheel. The winner is chosen fairly with the Web Crypto API before the wheel starts, and the animation lands exactly on that name, so long names and fast spins never affect the odds. You can remove each winner to draw again.

How to use it

  1. Paste or type names, one per line or separated by commas.
  2. Click Spin.
  3. Turn on 'Remove the winner' to draw several people without repeats.

Frequently asked questions

Is the wheel fair?

Yes. Every name has exactly the same chance, using unbiased cryptographic randomness.

How many names can I add?

Up to 500. The labels shrink to fit as the wheel fills up.

Are my names saved?

Only in your browser's local storage, so they're there next time. They're never uploaded.
