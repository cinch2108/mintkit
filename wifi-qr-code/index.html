Wi-Fi QR Code Generator: Share Your Network Password

How it works

The code uses the standard WIFI: format that the iPhone and Android cameras understand. Special characters in the network name and password (such as ; , : and \) are escaped correctly, so even complex passwords work. Your password never leaves your browser.

How to use it

  1. Enter your network name (SSID) exactly as it appears, including capitals.
  2. Enter the password and choose the security type (WPA/WPA2/WPA3 for most routers).
  3. Tick 'Hidden network' if your SSID isn't broadcast.
  4. Download and print it, then point a phone camera at it to join.

Frequently asked questions

Is it safe to make a Wi-Fi QR code here?

Yes. The code is created in your browser and nothing is uploaded. Anyone who can scan the printed code can read the password, though, so only show it where you'd share the password anyway.

Does it work on iPhone and Android?

Yes. iOS 11+ and Android 10+ can join from the built-in camera app. Older Android phones may need Google Lens.

Which security type should I pick for WPA3?

Choose WPA / WPA2 / WPA3. The WPA value covers all modern personal Wi-Fi security.
