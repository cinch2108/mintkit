File Checksum Calculator: Verify SHA-256 & MD5 of Downloads

How it works

Choose or drag in a file to calculate its MD5, SHA-1, SHA-256, SHA-384 and SHA-512 checksums. The file is read locally by your browser and never uploaded, so it works for private files too. Files up to 512 MB are supported.

How to use it

  1. Drag a file onto the drop zone, or click to choose one.
  2. Wait for the hashes to appear.
  3. Paste the publisher's checksum into the compare box to verify it.

Frequently asked questions

Why verify a checksum?

It confirms that the file you downloaded is exactly what the publisher released, with no corruption or tampering along the way.

Is my file uploaded?

No. It's read and hashed entirely in your browser.

Which checksum do publishers usually give?

Most now publish SHA-256. Older projects may list MD5 or SHA-1, and Mintkit shows them all.
