Hash Generator: MD5, SHA-1, SHA-256, SHA-384, SHA-512

How it works

Type text or choose a file and see all five common hashes at once. The SHA family uses your browser's built-in Web Crypto implementation, and MD5 uses Mintkit's own implementation, tested against the RFC 1321 vectors. Text is hashed as UTF-8.

How to use it

  1. Choose Text or File.
  2. Type or paste text, or pick a file.
  3. Choose hex or Base64 output, and paste an expected hash to compare.

Frequently asked questions

Which hash should I use?

Use SHA-256 for checksums and integrity checks. MD5 and SHA-1 are fine for detecting accidental changes but are broken for security.

Can a hash be reversed?

No. Hashes are one-way. Short or common inputs can be found by guessing, though, so never use a plain hash to store passwords.

Why does my hash differ from another tool's?

Check for a trailing newline or space, and that both tools use UTF-8. Changing a single byte changes the whole hash.
