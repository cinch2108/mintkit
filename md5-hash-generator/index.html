MD5 Hash Generator: Text & File MD5 Checksum

How it works

Mintkit's MD5 follows RFC 1321 and is tested against its official vectors, such as MD5('abc') = 900150983cd24fb0d6963f7d28e17f72. Files are processed in 4 MB chunks, so even large files hash without freezing the page.

How to use it

  1. Type text, or switch to File and choose a file.
  2. Copy the 32-character hex hash.
  3. Paste a published MD5 into the compare box to check a download.

Frequently asked questions

Is MD5 secure?

Not for security. Collisions can be created on purpose. It's still widely used to detect accidental corruption in downloads.

How long is an MD5 hash?

128 bits, shown as 32 hexadecimal characters.
